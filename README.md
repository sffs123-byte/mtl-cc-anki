# 실기 암기 정리 by. MTL — CC Anki

첨부 Word 원문을 CC별로 복습하는 웹 안키입니다. 기존 `sffs123-byte/cpx-a-mnemonic-anki`의 학습 화면을 재사용하며, 기존 사이트와 학습 저장소는 변경하지 않습니다.

- CC 61개 + 공통 양식 17개 = 78개 카드
- CC별 전체 원문과 관련 공통 문진 양식 수록
- 원문 표 70개, 표 밖 메모와 삽입 이미지 포함
- 글자색, 강조, 형광펜, 취소선, 병합 셀과 열 비율 보존
- 비교표는 각 CC에 전체를 포함하므로 공통/비교 내용이 의도적으로 중복됩니다.
- 순서/랜덤 복습, CC 단독 복습, SRS, 답안 편집, 브라우저 저장 및 JSON 백업
- `MTL-CC.apkg`: Anki용 CC별 하위 덱
- `original.docx`: 변경하지 않은 원본
- `source.html`: 원문 전체의 HTML 변환본
- `manifest.json`: 카드별 원문 body 블록 매핑

## 원문 보존 범위

원문 오탈자·약어·수치를 임의로 교정하지 않았습니다. HTML은 웹 글꼴과 화면 너비에 따라 줄바꿈·페이지 배치가 Word와 달라질 수 있습니다. 넓은 표는 가로 스크롤됩니다. Word 자체의 완전한 서식 정본은 `original.docx`입니다.
